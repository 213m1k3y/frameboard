FRAMEBOARD v4 — integrated build

This is an update to the original Frameboard v3, not a separate folder-only app.

Added:
- User-created, user-named folders in the Image Library.
- Folder tree with All Images and Unsorted.
- Rename folders.
- Move images by dragging them onto folders.
- Image rename/delete/move actions.
- IndexedDB storage for the library and storyboard data.
- Migration of images from the original v3 localStorage library into Unsorted.
- Storyboard tab connected to the same image library.
- Add an image from the library to a storyboard.
- Paste images directly into the storyboard.
- Multiple storyboard boards.
- Storyboard placements retain their own image data, so deleting a source image from the library does not remove an existing storyboard placement.

Open index.html in a modern browser.
