FRAMEBOARD — INSTALLABLE WEB APP

This folder is a Progressive Web App (PWA). It must be served over HTTPS (or localhost) for Chrome/Samsung Internet to offer Install App and for the service worker to work.

Recommended Android setup:
1. Upload this folder's contents to a static HTTPS host (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Open the resulting HTTPS address in Chrome on Android.
3. Use Chrome's menu > Add to Home screen / Install app.
4. Launch Frameboard from the new home-screen icon.

Your library/storyboards are stored in the browser's IndexedDB on that device/browser.
